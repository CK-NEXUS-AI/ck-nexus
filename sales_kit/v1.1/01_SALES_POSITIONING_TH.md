# CK-NEXUS — Sales Positioning (TH)

## สินค้าที่ขาย
**CK-NEXUS Creator Source Edition — Beta** เป็นแพ็กซอร์สโค้ด AI web application สำหรับผู้ซื้อที่ต้องการนำไปใช้งาน ทดลอง ปรับแต่ง และพัฒนาต่อยอดภายใต้สิทธิ์ที่ระบุในสัญญาซื้อขาย/ไลเซนส์ที่ลงนามจริง

## จุดขายหลัก
- ได้ source code ไม่ใช่แค่สิทธิ์ใช้ SaaS
- มี Demo Mode ให้ทดสอบโดยไม่ต้องใช้ OpenAI API key
- มี Creator Agents, run history, session memory และ API สำหรับระบบหลัก
- มี Credential Broker / fail-closed security boundaries / integration status mechanisms
- มี automated tests, frozen dependency lock, release packaging และ SHA-256 verification
- มี Buyer Quick Start, Known Limitations, acceptance checklist และ commercial schedule template

## Positioning ที่ใช้ได้
> ซื้อฐานระบบ AI ที่มีโค้ดจริง เอกสารจริง และหลักฐาน build/test พร้อมนำไปปรับแบรนด์และพัฒนาต่อ โดยไม่ต้องเริ่มจากศูนย์

## Classification ที่ต้องพูดเสมอ
- SELLABLE_SOURCE_BETA
- ไม่ใช่ Production Ready
- Production gate Q10-Q16 ยังไม่ครบ

## สิ่งที่ไม่ได้รวม
- API keys, OAuth tokens, account credentials หรือ private keys ของผู้ขาย
- API credits / cloud credits / third-party subscriptions
- domain, hosting หรือ production infrastructure เว้นแต่ระบุในสัญญาแยก
- การรับรองว่าไม่มี bug หรือไม่มีช่องโหว่
- การรับประกัน Production/Enterprise readiness

## Buyer profile ที่เหมาะ
- developer / agency ที่ต้องการ source AI product เพื่อนำไป customize
- creator business ที่มีทีมเทคนิคหรือผู้รับจ้างดูแล
- startup ที่ต้องการ MVP foundation เร็วกว่าสร้างใหม่ทั้งหมด
- buyer ที่เข้าใจว่า Beta source product ต้องมี deployment/security qualification ของตนเองก่อน production

## Buyer profile ที่ไม่เหมาะ
- ผู้ซื้อที่ต้องการ SaaS สำเร็จรูปแบบไม่ต้องดูแลระบบเลย
- ผู้ซื้อที่ต้องการ production SLA/enterprise certification ทันที
- ผู้ซื้อที่คาดหวัง API usage ฟรีไม่จำกัด
