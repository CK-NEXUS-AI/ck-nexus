# Demo Script 10 นาที

## 0:00–1:00 — ตั้ง expectation
พูดว่า: “นี่คือ CK-NEXUS Creator Source Edition — Beta ขายเป็น source-code product ไม่ได้เคลม Production Ready จุดเด่นคือผู้ซื้อได้ฐานระบบจริงพร้อม Demo Mode, tests, docs และ package identity ตรวจสอบได้”

## 1:00–2:30 — เปิดระบบ
- ใช้ Demo Mode
- เปิดหน้าเว็บ local
- แสดง health/status
- ชี้ให้เห็นว่า demo ใช้ได้โดยไม่ต้องใส่ OpenAI key

## 2:30–4:30 — Creator workflow
- เลือก Creator Agent
- ใส่ brief สั้น
- รันงาน demo
- แสดงผลลัพธ์และ run history

## 4:30–5:30 — Memory / history
- เปิดรายการ run เดิม
- แสดง session/history behavior
- อธิบายว่าผู้ซื้อสามารถปรับ backend/storage ต่อได้

## 5:30–6:30 — API / developer value
- เปิด `/docs`
- แสดง endpoints สำคัญ เช่น health, agents, runs, integration status
- เน้นว่าเป็น source foundation ไม่ใช่ black-box SaaS

## 6:30–7:30 — Security boundary
- แสดง redacted integration/credential status
- อธิบายว่า package ไม่ส่ง API keys/tokens ของผู้ขาย
- buyer ต้องใส่ credentials ของตัวเอง

## 7:30–8:30 — Evidence / packaging
- เปิด release identity / checksum
- อธิบาย SHA-256 verification
- แสดง automated CI/release packaging concept

## 8:30–9:15 — Limitations แบบตรงไปตรงมา
พูดว่า: “รุ่นนี้ Beta ใช้งานและพัฒนาต่อได้ แต่ Q10-Q16 ยังไม่ Production GO ดังนั้นผมไม่ขายคำว่า Production Ready ให้คุณ ผมขาย source foundation ที่ตรวจสอบตัวตนไฟล์ได้”
