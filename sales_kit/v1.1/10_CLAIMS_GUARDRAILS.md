# Sales Claims Guardrails — INTERNAL

## ใช้ได้
- “Creator Source Edition — Beta”
- “SELLABLE_SOURCE_BETA”
- “มี Demo Mode และ source code”
- “มี automated test/release tooling”
- “มี integrity-bound ZIP และ SHA-256”
- “ผู้ซื้อ provision credentials ของตนเอง”
- “สามารถพัฒนาต่อได้ตามสิทธิ์ในสัญญา”

## ห้ามใช้จนกว่าจะมีหลักฐานใหม่
- “Production Ready”
- “Enterprise certified”
- “Q01-Q16 ผ่านครบ”
- “ปลอดภัย 100% / ไม่มีช่องโหว่”
- “ไม่มี bug”
- “AI ฟรีไม่จำกัด”
- “รวม API credits ไม่จำกัด”
- “เชื่อมบัญชีของผู้ขายไปให้ลูกค้า”
- “มี 63 skills/240 capabilities ที่ verified แล้ว”
- “ดูดซับ model weights/hidden prompts/ความสามารถลับจากโมเดลอื่น”
- “OpenAI/Claude/Gemini model รวมอยู่ใน source package”

## Rule
ทุก claim ที่เกี่ยวกับ production, security, live integrations, model/provider access หรือ benchmark ต้องผูกกับ evidence ของ exact subject/version นั้น ไม่ใช้ข้อความสรุปเก่ามาแทนหลักฐาน
