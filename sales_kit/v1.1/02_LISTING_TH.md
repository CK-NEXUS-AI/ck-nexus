# ข้อความประกาศขาย — ภาษาไทย

## CK-NEXUS Creator Source Edition — Beta

ขายซอร์สระบบ AI พร้อมโค้ด เอกสารติดตั้ง ระบบ Demo และแพ็กส่งมอบตรวจสอบ SHA-256 ได้

เหมาะสำหรับนักพัฒนา เอเจนซี Creator Business และ Startup ที่ต้องการมีฐานระบบ AI ของตัวเองเพื่อนำไปปรับแบรนด์ เพิ่มฟังก์ชัน หรือพัฒนาต่อ โดยไม่ต้องเริ่มระบบทั้งหมดจากศูนย์

### สิ่งที่ผู้ซื้อได้รับ
- CK-NEXUS source-code delivery package
- Responsive Thai web application
- Creator Agents และ Demo Mode
- local run history / session memory
- API endpoints และ OpenAPI docs
- integration status/test mechanisms
- Credential Broker และ fail-closed security controls ที่มีอยู่ในรุ่นส่งมอบ
- automated test/release tooling
- installation guide, known limitations, acceptance checklist
- release identity และ SHA-256 checksum
- commercial license/assignment template สำหรับกรอกเงื่อนไขธุรกรรมจริง

### หมายเหตุสำคัญ
รุ่นนี้ขายในสถานะ **Creator Source Edition — Beta / SELLABLE_SOURCE_BETA** ไม่ได้โฆษณาเป็น Production Ready และ Production gates Q10-Q16 ยังไม่ครบ ผู้ซื้อเป็นผู้จัดหา API keys, third-party accounts, hosting และค่าใช้บริการภายนอกของตนเอง

สนใจสามารถขอ Demo flow, acceptance checklist และรายละเอียดขอบเขตซอร์สก่อนทำสัญญาได้
