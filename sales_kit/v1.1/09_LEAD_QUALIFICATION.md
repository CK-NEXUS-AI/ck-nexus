# Lead Qualification

ถามก่อนเสนอราคาเพื่อไม่ขายผิดกลุ่ม:

1. ต้องการ source ไปใช้เอง, customize ให้ลูกค้า หรือทำสินค้าใหม่?
2. มี developer/agency ดูแล deployment หรือไม่?
3. ต้องการ Demo/Beta foundation หรือจำเป็นต้อง Production-certified ทันที?
4. ต้องการ source assignment หรือ perpetual source license?
5. ต้องการ support แค่ติดตั้ง หรือมี custom development?
6. มี provider/API accounts ของตนเองหรือไม่?
7. target deployment คือ local, VPS หรือ cloud ใด?
8. มี deadline และ budget เท่าไร?

## Green flags
- เข้าใจ source product และมี technical capacity
- ยอมรับ Beta classification
- เห็นคุณค่าของการซื้อ foundation แทนสร้างใหม่
- พร้อม provision provider credentials เอง

## Red flags
- ขอ seller API keys/accounts/credits
- ต้องการ “ฟรีไม่จำกัด”
- ขอให้รับรอง zero bugs/zero vulnerabilities
- ต้องการ Production SLA ในราคา Beta โดยไม่ทำ qualification เพิ่ม
- ขอสิทธิ์ที่ไม่อยู่ใน commercial schedule
