# Launch Checklist

## Listing ready
- [ ] product name says Creator Source Edition — Beta
- [ ] asking price and inclusions match current seller decision
- [ ] no Production Ready claim
- [ ] no unlimited/free API claim
- [ ] no seller credentials/account access included

## Lead ready
- [ ] intake complete
- [ ] technical fit recorded
- [ ] intended use understood
- [ ] limitations disclosed

## Quote ready
- [ ] buyer/legal name correct
- [ ] transaction model selected
- [ ] exact product scope stated
- [ ] price/currency/taxes/payment terms stated
- [ ] support scope stated or excluded
- [ ] validity/acceptance terms stated

## Delivery ready
- [ ] payment verified using approved channel
- [ ] exact buyer ZIP selected
- [ ] SHA-256 verified
- [ ] seller-only kit excluded
- [ ] secrets/user data absent
- [ ] executed agreement attached separately where required
- [ ] handover record created

## Close
- [ ] buyer verified checksum
- [ ] Demo Mode acceptance completed
- [ ] acceptance status recorded
- [ ] support start/end dates recorded if purchased
