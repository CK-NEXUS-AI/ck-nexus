# Optional Support Options

These are seller-side offer components, not obligations until written into the executed commercial schedule.

## Source Delivery Only
- verified source package + checksum
- included buyer documentation
- no ongoing engineering commitment beyond the signed terms

## Remote Onboarding Add-on
Suggested scope:
- one installation session
- environment setup guidance
- Demo Mode verification
- buyer-owned Live Mode credential configuration guidance
- no handling or retention of buyer secrets by the seller

## Integration Advisory Add-on
Suggested scope:
- architecture review for buyer-selected integrations
- read-only connector planning first
- side-effect/OAuth/production changes only under a separately agreed implementation scope

## Upgrade Path Add-on
If a future CK-NEXUS Production Edition passes the required gates, an upgrade may be separately quoted. Do not promise a date, automatic entitlement, or Production certification unless the signed agreement explicitly provides it.

Every support offer must state duration, hours/sessions, response expectations, exclusions, price/tax treatment and termination/refund terms in the transaction-specific agreement.
