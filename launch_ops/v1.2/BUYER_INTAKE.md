# Buyer Intake

Collect only information needed to qualify and deliver the source-code product.

## Required
- buyer / legal entity name
- primary contact name
- contact email or agreed communication channel
- intended use: internal / client project / product development / evaluation
- technical owner or developer contact
- target OS/environment
- whether buyer needs only source delivery or optional onboarding/support
- desired transaction model: perpetual source license or assignment, subject to executed agreement
- expected purchase timing

## Technical fit
Ask whether the buyer can provide:
- Python 3.11+
- local/server environment under buyer control
- buyer-owned OpenAI/API credentials if Live Mode is required
- HTTPS/reverse proxy and access token if exposing the app publicly

## Mandatory disclosure before close
The buyer must be told:
- this package is Creator Source Edition — Beta;
- Demo Mode can be used without an API key;
- Live provider use requires buyer-owned credentials;
- it is not represented as Production Ready;
- Q10-Q16 production qualification is incomplete;
- third-party accounts, API credits, domains, hosting and credentials are not included unless a signed schedule expressly says otherwise.

Do not collect passwords, API keys or OAuth tokens in this intake.
