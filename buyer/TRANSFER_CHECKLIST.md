# Transfer Checklist

Before buyer handoff:
- verify package SHA-256
- verify canonical commit/tree
- verify source manifest and per-file hashes
- review fresh validation outputs
- review `KNOWN_LIMITATIONS.md`
- review `DEVELOPMENT_CANDIDATES_NOT_INCLUDED.md`
- rotate/remove seller credentials before infrastructure transfer
- do not include passwords, API keys, refresh tokens, private keys, OTPs, or personal account secrets
- transfer domains/cloud/VPS/GitHub access only through an agreed secure process
- agree separately on price, license/assignment terms, support period, warranties and indemnities

A ZIP file alone does not transfer release authority or external certification.
