## Evidence hygiene decision

Earlier helper workflows wrote new scanner output inside the repository's existing `evidence/` directory. That caused uploaded bundles to include unrelated pre-existing repository evidence. Individual scanner JSON files remain useful, but those mixed bundles are not clean enough for canonical evidence packaging.

Permanent operating policy now requires:

- isolated scanner output directories;
- explicit scan scope;
- subject SHA/tree binding;
- tool version and container image digest;
- raw exit code retention;
- SHA-256 hashing before archive;
- separation of current-tree and full-history secret findings.
