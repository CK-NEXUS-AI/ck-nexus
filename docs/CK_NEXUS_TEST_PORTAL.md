# CK-NEXUS Test Portal

This static GitHub Pages interface provides a read-only browser connection test for `GET /health` and `GET /api/status`. It does not store credentials or issue write operations. The API must use HTTPS and allow browser CORS for the Pages origin. A successful HTTP response is not Production certification.

The preview is published from the `docs/` folder on `feat/ck-nexus-test-portal`. After review and merge, update the Pages source branch to `main` to publish the same site from the canonical branch.
