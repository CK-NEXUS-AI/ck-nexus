# CK-NEXUS Brand Guide

## Positioning

**CK-NEXUS — Governed AI Agent Execution Control Plane**

Use CK-NEXUS as the primary brand name. The repository remains `ck-nexus`.

## Visual system

- **Primary type:** Inter or Geist
- **Technical type:** JetBrains Mono
- **Mark:** Nexus Gate — a geometric control boundary with a central decision node
- **Tone:** precise, engineered, governed, calm
- **Avoid:** robot heads, brains, generic circuit-board artwork, stock AI imagery

## Color roles

The SVG assets use a restrained dark technical base with a violet-to-cyan accent gradient.

- Base: near-black / zinc
- Text: off-white
- Muted text: zinc
- Accent: violet → cyan

These are brand roles, not a claim about application UI colors.

## GitHub usage

- Repository avatar / social preview: `assets/brand/logo-mark.svg`
- README hero: `assets/brand/logo.svg`
- Documentation wordmark: `assets/brand/wordmark.svg`
- Code/CLI surfaces: Inter/Geist for prose, JetBrains Mono for identifiers and commands

## Evidence rule

Brand assets are presentation-only. They do not change implementation, security posture, runtime verification, or production status.

Never use the visual layer to imply:

- production certification
- live provider authorization
- recurring revenue
- independent verification that has not been evidenced

## Change boundary

This brand slice intentionally changes only presentation/documentation assets. Runtime logic and security controls are out of scope.
