# Sellable Edition Boundaries

Status: product packaging guidance, not a Production GO declaration.

## Creator / Developer Source Edition

May be sold with explicit limitations when its bounded local/demo features pass their package tests. Suitable claims include local web UI, Creator Agents, Demo Mode, local history/session behavior and documented optional integrations that are actually implemented.

Must not be marketed as enterprise multi-node/autonomous production infrastructure when those capabilities are only architecture targets.

## Buyer Beta / Staging Edition

Requires reproducible package/install, isolated staging setup, documented credential setup by owner, regression/evidence bundle, known limitations and no implied Production GO. External connectors are advertised only with verified supported capability/scope semantics.

## Production Core Edition

Requires Q01-Q16 as defined by the release program, including genuine Q10 security evidence, isolated staging, live observability alert evidence, recovery drill and fresh release provenance.

## Full Autonomous Platform Edition

Adds completed runtime Fabrics, governed self-expansion/marketplace, multi-provider Cognitive Governor, durable AGNES automation, recovery/observability and enterprise control surfaces after the corresponding implementation/evidence gates.

## Commercial claim rule

Marketing/docs are generated from a capability/release manifest. Planned/spec-only features are labeled planned/preview; external platform connection does not imply every external platform API feature is implemented in CK-NEXUS.
