## Findings

### 1. Prompt "secret codes" are not a reliable product concept

The useful idea is not hidden codes. The useful idea is a transparent mode registry:
- expert
- brief
- compare
- research
- brainstorm
- SEO
- AI-search
- creator
- repurpose
- privacy-check

CK-NEXUS may accept familiar slash aliases, but it must label them as CK-NEXUS modes rather than official ChatGPT commands.

### 2. Creator workflow is the strongest reusable concept

Canonical CK-NEXUS already has:
- Content Strategist
- Script Writer
- Repurpose Studio
- Editorial Reviewer
- Idea Engine
- provider routing
- privacy firewall
- personal intelligence
- evidence and governance

Therefore do not build a second content platform. Extend the existing system with:
1. Research
2. Plan
3. Create
4. Review / fact-check
5. Repurpose
6. Search optimization
7. Publish-draft handoff
8. Measure
9. Learn

External publishing remains permissioned and is never implied by a content plan.

### 3. SEO / AEO / GEO should be one evidence-aware discovery layer

Google states that normal SEO fundamentals continue to apply to AI Overviews and AI Mode; there is no special schema or magic AI-only markup requirement.

CK-NEXUS target:
- search intent
- crawl/index readiness
- structured content
- original value
- evidence and citations
- useful images/video
- structured data that matches visible content
- quality and spam checks
- measurement via Search Console / analytics connectors where authorized

Treat GEO as a research/measurement concept, not a guaranteed ranking recipe.

### 4. Privacy infographic needs correction before reuse

Useful surfaces:
- search/activity history
- location signals
- browser/device/app information
- ads personalization
- account sync and service-specific data

But the infographic overgeneralizes. Google exposes controls for activity/history, personalization, ads, and location. My Activity does not itself store Gmail message content, Drive files, or Photos content.

CK-NEXUS should model privacy as:
data_type -> source -> purpose -> retention/control -> consent -> external disclosure -> deletion/revocation

Do not produce alarmist statements such as "complete privacy is impossible" as a system fact.

### 5. Facebook Creator Fast Track is real, but the image is incomplete

Meta launched Creator Fast Track in 2026 for established creators coming to or returning to Facebook. Official eligibility and payouts are program-specific and may change.

The durable product lesson is:
- originality score
- provenance
- duplicate/reupload detection
- qualified-view analytics
- watch-time / engagement metrics
- monetization eligibility as external platform state

Do not hard-code payout or eligibility numbers into CK-NEXUS runtime.

### 6. "56 free AI tools" is not a trustworthy pricing source

Many products in the image are freemium, trial-based, subscription-only, or charge for APIs.

CK-NEXUS rule:
- never classify a provider as FREE based only on marketing/social posts
- separate UI free plan from API free tier
- record source, checked_at, scope, quota model, and uncertainty
- fail closed when current pricing evidence is unavailable

### 7. Multimodal provider taxonomy is a genuine gap

Add capability classes independently of vendor:
- text_generation
- web_research
- image_generation
- image_editing
- video_generation
- video_editing
- speech_to_text
- text_to_speech
- music_generation
- presentation_generation
- design_generation
- social_publish
- analytics
- seo_research
- automation

Vendor adapters should be optional and replaceable.

## Vendor/API research leads

Confirmed from official documentation during this research pass:
- Runway has a developer API for generative media.
- ElevenLabs has REST/WebSocket APIs and official Python/JavaScript SDKs; API keys support scope and quota restrictions.
- Gamma Generate API v1.0 is available but requires an eligible paid plan.
- Ideogram has an API, but API billing is separate from the consumer subscription.
- Perplexity provides Search, Sonar, Agent and Embeddings APIs.

These are integration candidates, not automatic adoption decisions.
