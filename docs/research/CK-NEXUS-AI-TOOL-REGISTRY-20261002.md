## Evidence status

This is an **intake dataset**, not a verified pricing or capability directory. Every `FREE` claim supplied by the user is recorded as **USER_CLAIM / NOT_YET_VERIFIED**. A free web tier does not imply unlimited use, free API access, free commercial use, or production suitability.

**Canonical rule:** NO EVIDENCE → NO DONE.

## Admission lifecycle

`DISCOVERED → AUDIT_PENDING → PARTIAL → VERIFIED → ADMITTED`  
Exceptions: `BLOCKED`, `REJECTED`.

## Required verification gates

1. Official identity/domain
2. Current pricing/free-tier terms
3. API availability and quotas
4. MCP/native agent integration, if claimed
5. OAuth/authentication model
6. Open-source/license status
7. Commercial-use terms
8. Privacy/data retention/training policy
9. Security controls and supply-chain posture
10. Automation/webhook capabilities
11. Agent/tool execution scope
12. Reproducible test where practical
13. Evidence URL + retrieval date
14. CK-NEXUS policy/risk classification

## Safety boundary

No credentials, OTPs, API keys, paid actions, account creation, OAuth grants, production mutations, or automatic deployment are part of this intake. CK-NEXUS production remains **NO-GO** independently of this registry.
