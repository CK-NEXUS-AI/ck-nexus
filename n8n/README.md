# n8n Integration Templates — Release Candidate

These files are credential-free **templates**, intentionally inactive. They must be imported into the customer's own n8n staging instance, bound to customer credentials/secrets, tested, audited, then activated.

They are not evidence that P0 n8n gates have passed. Runtime execution IDs from the exact pinned n8n instance are required for GA promotion.

Expected CK-NEXUS API base inside Compose: `http://app:8000`.
