AI Workflow Builder · สร้างงานด้วยภาษาไทย

อธิบายงานที่ต้องการ ระบบจะสร้างแผนและไฟล์ JSON สำหรับนำเข้า n8n ตรวจสอบข้อมูลและ credentials ก่อนเปิดใช้งานทุกครั้ง

ตัวสร้างรุ่นแรกสร้างฉบับร่างจากแม่แบบที่ตรวจสอบได้ ยังไม่เรียก AI model ภายนอก และยังไม่บันทึกเข้าบัญชี n8n โดยอัตโนมัติ

แผนการทำงาน

    แผนผัง Workflow ที่เปิดใช้งาน

    แสดงเฉพาะ Workflow ที่มีสถานะ Active เพื่อไม่ให้สับสน

    กำลังโหลด Workflow ที่เปิดใช้งาน…

    แผนผังใช้ชื่อโหนดและเส้นเชื่อมจาก n8n จริง โดยไม่ส่งค่าพารามิเตอร์หรือข้อมูลลับไปยังเบราว์เซอร์

    ◷

    ประวัติการทำงาน

    การแสดง execution history จะเปิดใช้หลังเพิ่ม endpoint อ่านประวัติที่ผ่านการทดสอบ contract แล้ว

    สถานะ: ยังไม่รองรับการแสดงประวัติในหน้านี้

    การเชื่อมต่อ

    ตรวจสถานะ gateway และการเชื่อมต่อ n8n โดยไม่เปิดเผยข้อมูลลับ
