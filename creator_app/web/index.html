PYTHON 3.11+ / LOCAL DEVELOPMENT

Run the canonical application.

Linux / macOS:

cp .env.example .env.local
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -e ".[dev]"
python3 -m creator_app.unified

Windows PowerShell:

Copy-Item .env.example .env.local
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m creator_app.unified

Open http://127.0.0.1:8000. Use .env.local for local secrets; never commit it.

SECURITY / AUTHORITY BOUNDARIES

Operate safely. Verify every claim.

  • Keep Production status at NO-GO until all mandatory gates pass on the exact release commit.
  • Keep MCP bound to 127.0.0.1:8765; do not expose it directly to the public Internet.
  • Keep credentials server-side. Never place keys, tokens, or private keys in source, browser code, screenshots, or logs.
  • Reconcile repository, runtime, test, and release evidence before deployment.
  • External tools are adapters only; CK-NEXUS Core retains policy and release authority.
