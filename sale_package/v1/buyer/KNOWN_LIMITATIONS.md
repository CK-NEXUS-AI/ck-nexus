# Known Limitations — Sale Package v1

This document is part of buyer acceptance.

- Classification: Creator Source Edition — Beta / Developer source product.
- Production status: NO-GO until Q10-Q16 are complete on the final immutable release identity.
- Q10 Deep Security is the earliest incomplete production release gate.
- The package is not an Enterprise multi-node production platform certification.
- Telegram, marketplace, billing UI and customer portal are not part of the current Creator Edition product promise.
- Live provider operation depends on buyer credentials, provider account status, quotas, network availability and provider terms.
- Third-party OAuth authorization normally requires the account owner/user to grant consent; the package does not bypass login, MFA or consent.
- API keys, OAuth tokens, paid credits, cloud subscriptions, domains and third-party accounts are not included unless the executed commercial schedule explicitly says otherwise.
- Public internet deployment requires buyer-operated HTTPS, secret management, access control, monitoring and appropriate infrastructure hardening.
- Architecture work in open/draft branches is not automatically part of the delivered runtime unless its exact commit/artifact is listed in the signed schedule.
- Seller templates are not legal advice; transaction documents should receive appropriate legal review.
