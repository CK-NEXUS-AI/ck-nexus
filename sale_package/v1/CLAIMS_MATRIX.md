# Sale Claims Matrix

## Allowed claims

- CK-NEXUS Creator Source Edition / Beta / Developer Edition.
- Source-code delivery with documented build, tests and Demo Mode.
- Buyer can run the included Demo Mode without a live AI API key when configured as documented.
- Source includes CK-NEXUS Creator runtime, agent catalog, local session/history storage, Development Council and existing integration/runtime foundations.
- Prior CI/security/dependency/live-backend evidence exists for earlier release gates on the frozen runtime subject.

## Claims that require qualification

- "AI integrations included" means source/runtime integration capability is included; third-party accounts, OAuth grants, paid plans and API credits are not transferred.
- "Live AI supported" means buyer-supplied valid credentials are required and provider availability/terms are external dependencies.
- "Commercial use" depends on the executed CK-NEXUS commercial schedule plus all applicable third-party licenses.

## Prohibited claims for Sale Package v1

- Production Ready.
- Enterprise Production Ready.
- Security certified / penetration-tested complete.
- Q01-Q16 complete.
- Unlimited free API usage.
- Includes transferable third-party API credits/accounts/tokens.
- Permanently self-learning or incapable of forgetting.
- Copies proprietary model weights, hidden prompts or private skills from external AI providers.
